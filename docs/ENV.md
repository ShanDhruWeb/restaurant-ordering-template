# Environment variables

The app checks these when it starts and refuses to run with a message naming each missing or invalid variable. Locally they live in `.env` (never committed). On Vercel, set them under **Project → Settings → Environment Variables**.

| Variable                  | Required          | Example                                                   | Notes                                                                                                                                                                                           |
| ------------------------- | ----------------- | --------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `DATABASE_URL`            | yes               | `postgresql://…-pooler….neon.tech/neondb?sslmode=require` | **Pooled** connection string, used by the running app. On Neon the host contains `-pooler`.                                                                                                     |
| `DATABASE_URL_UNPOOLED`   | for migrations    | `postgresql://….neon.tech/neondb?sslmode=require`         | **Direct** (non-pooled) string, used only by `prisma migrate`. Falls back to `DATABASE_URL` if empty.                                                                                           |
| `DATABASE_URL_TEST`       | tests only        | separate database                                         | Integration tests **wipe every table** here. Never point it at dev or production; the tests refuse if it matches `DATABASE_URL`/`DATABASE_URL_UNPOOLED`. Leave empty to skip integration tests. |
| `RAZORPAY_KEY_ID`         | yes (unless mock) | `rzp_test_…` / `rzp_live_…`                               | From Razorpay Dashboard → Account & Settings → API Keys. The prefix decides test or live mode. Sent to the browser (it is public).                                                              |
| `RAZORPAY_KEY_SECRET`     | yes (unless mock) |                                                           | **Secret.** Server only. Signs and checks checkout responses.                                                                                                                                   |
| `RAZORPAY_WEBHOOK_SECRET` | yes (unless mock) |                                                           | **Secret.** The secret you type when creating the webhook in Razorpay.                                                                                                                          |
| `RAZORPAY_MOCK`           | dev/tests only    | `true`                                                    | Simulates Razorpay locally, no keys needed. **The app refuses to start with this in production.**                                                                                               |
| `ALLOW_TEST_KEYS`         | optional          | `true`                                                    | Production refuses `rzp_test_` keys unless this is `true`. Use only for a staging site.                                                                                                         |
| `SESSION_SECRET`          | yes               | 64 hex characters                                         | Signs staff login cookies. At least 32 characters. Generate: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`. Changing it logs every staff member out.               |
| `NEXT_PUBLIC_SITE_URL`    | yes               | `https://order.demokitchen.in`                            | Public URL, no trailing slash. Used in QR codes, social tags and the CSRF origin check.                                                                                                         |
| `CRON_SECRET`             | yes               | 32+ random characters                                     | Protects `/api/cron/reconcile`. Vercel Cron sends it automatically as `Authorization: Bearer …` when the variable is set.                                                                       |
| `SENTRY_DSN`              | optional          | `https://…@….ingest.sentry.io/…`                          | Server errors are reported to Sentry when set. Leave empty to disable.                                                                                                                          |

Never paste `RAZORPAY_KEY_SECRET`, `RAZORPAY_WEBHOOK_SECRET`, `SESSION_SECRET` or database passwords into chat, tickets or the README. Logs redact any field whose name contains `secret`, `signature`, `password`, `token` or `key_id`.
